One place to ask, plan and ship

✦

Chat

Streaming replies with Markdown, tables and highlighted code. Regenerate, edit and resend, and pick any model you have a key for. Conversations sync across your Macs.

⚙

Coding agent

Describe a task and approve the plan. The agent works on its own vard/… branch, so your checkout is never touched. Risky commands wait for you. Your tests run before it says it's done, then you merge or discard. It remembers each project's conventions and past fixes for next time.

⚿

Your keys, your Mac

Starts free with a Groq key (GPT-OSS 120B). Also works with Anthropic, OpenAI, Gemini, OpenRouter or local Ollama. Keys live in the macOS Keychain and only go to the provider you chose.

Command line

vard in your terminal

The same chat and coding agent as a full-screen terminal app: streamed replies, steps that tick off as the agent works, pop-ups for approvals and merging, a status bar, and / commands with autocomplete. It uses the keys you saved in the app.

Install

In the app: Settings → Command-line tool → Install. Or on its own:

mkdir -p ~/.local/bin && curl -fsSL https://github.com/vardhan23v/Vard-AI/releases/latest/download/vard-macos-universal.gz | gunzip > ~/.local/bin/vard && chmod +x ~/.local/bin/vard
vard commands
vardFull-screen session: chat, and /task to run the agent in this repo
vard ask "…"One answer. Pipe in context: git diff | vard ask "review"
vard run "…"Agent task with inline approvals, for scripts too
vard keys, vard modelsKeys in the shared Keychain; the default model
vard --classicPlain line-by-line mode

Up and running in three steps

  1. 1

    Download

    Open the DMG and drag Vard AI to Applications. The CLI comes with it.

  2. 2

    Add a free key

    Create a key at console.groq.com and paste it in Settings → API keys.

  3. 3

    Chat or hand off a task

    Ask anything, or add a project folder and describe a change. Approve the plan and review the diff.

Installing

Vard AI isn't notarized by Apple yet, so macOS asks before the first launch. In Applications, right-click Vard AI and choose Open, then Open again. You only do this once.

If macOS says the app is damaged, clear the download flag and open it again:

xattr -dr com.apple.quarantine "/Applications/Vard AI.app"

When the app first reads a saved key, macOS asks for Keychain access: enter your password and choose Always Allow. Checksums are in the release.

Questions

Is it free?

Yes. The app and CLI are free and open source (MIT). You pay your model provider, if anything: Groq's free tier, local Ollama and OpenRouter's free models cost nothing.

Where do my API keys go?

Into your macOS Keychain. They are added to requests on your Mac and sent only to the provider you picked. Vard AI has no server that sees them.

Can the agent break my project?

Each task runs in its own git worktree on a vard/… branch, so your working copy isn't touched until you merge. Commands that aren't on your allowlist wait for approval, and dangerous ones like sudo or git push are blocked.

Does it remember my project?

Yes. Each project gets a memory file (.vard/memory.md) with its stack, conventions, decisions and past fixes, which the agent reads before every task. After a task, Vard suggests what to remember and you choose what's saved. It's plain Markdown on your Mac, so you can edit it.

Which Macs does it run on?

macOS 12 or later, on Apple Silicon and Intel (one universal download).

Windows or Linux?

Not yet. The app and the CLI are macOS-only for now.
